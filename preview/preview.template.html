Part 3 — What's behind the screens

Node.js + Express + MongoDB API

One REST API serves both clients. JWT is the default auth provider; flip AUTH_PROVIDER=firebase and the Firebase Admin SDK verifies tokens instead — controllers don't change.

Run it locally
# 1 · install everything (npm workspaces)
npm install

# 2 · configure
cp backend/.env.example backend/.env   # MONGODB_URI + JWT_SECRET
cp web/.env.example web/.env

# 3 · seed demo users, properties, leases
npm run seed

# 4 · start the stack
npm run dev:backend   # http://localhost:5000/api
npm run dev:web       # http://localhost:5173
npm run dev:mobile    # Expo → scan with Expo Go
🔐 Auth — swap in one env var

AUTH_PROVIDER=jwt → bcrypt + jsonwebtoken, 7-day tokens.
AUTH_PROVIDER=firebase → Firebase Admin verifies ID tokens from POST /api/auth/firebase-login and auto-creates the Mongo user.

💳 Payments

Stripe PaymentIntents are created server-side and a webhook marks rent paid. MVP flow confirms directly; drop in Stripe Elements on the web/mobile checkout for real card entry. PayPal is an open adapter slot in paymentController.js.

🔔 Notifications

Every lease decision, application, and maintenance update writes a Notification record and optionally sends an email (SMTP/Ethereal). Expo push is the remaining hook for mobile.
